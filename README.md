# CharlySki 🎿

Application web mobile personnelle pour Charlie.

## V1
- météo réelle via Open-Meteo, sans clé API
- CharlyScore sur 10
- comparaison Aujourd'hui / Demain / +2 jours
- favoris
- repère personnel Passe Montagne
- journal de saison
- checklist ski
- sauvegarde locale sur le téléphone

## Mise en ligne
Le projet est volontairement 100 % statique : un seul `index.html`.

### GitHub Pages
Settings > Pages > Deploy from a branch > `main` / `(root)`.

### Vercel
Importer le repository `Floydem/CharlySki`. Aucun framework, aucune commande de build et aucune variable d'environnement ne sont nécessaires.

> Le CharlyScore est un indicateur ludique basé sur les prévisions météo. Toujours vérifier l'ouverture réelle du domaine et les informations officielles de la station.
