# Skiory ⛷️🏔️

**Explore · Track · Higher**

Skiory est une PWA mobile dédiée au ski : découverte de stations, aide au choix selon la météo, collection personnelle de domaines et télémétrie GPS.

## Identité
- nouveau nom : **Skiory**
- interface premium sport-tech / alpine
- identité bleu nuit, cyan et blanc
- logo et icône dédiés intégrés à la PWA

## Fonctions
- catalogue transfrontalier France / Valais
- météo réelle via Open-Meteo
- **Skiory Score** et explication du choix
- Powder Alert
- carte des stations
- fiches station, webcams et infos officielles
- favoris et collection de stations
- télémétrie GPS : vitesse, distance, altitude, D+/D-, durée, tracé
- export GPX
- historique de saison et records
- checklist
- export / import de sauvegarde
- installation PWA sur iOS / Android

## Hébergement
Le projet reste statique et fonctionne directement sur GitHub Pages. Le repository conserve pour l’instant son nom historique `CharlySki`, mais l’application publique et la PWA sont désormais brandées **Skiory**.

## Données
Les favoris, profils, collection et sorties GPS restent stockés localement dans le navigateur. Les anciennes clés de stockage sont conservées en interne pour préserver les données déjà enregistrées lors du passage de CharlySki à Skiory.
